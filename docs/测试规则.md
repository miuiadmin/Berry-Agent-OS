# 测试规则

> BerryAgent 测试策略：三层分明，不造假信心

## 三层测试架构

| 层级 | 类型 | 运行时机 | LLM | 目标 |
|------|------|---------|-----|------|
| 1 | 单元测试 | 每次 commit / CI | 无（纯逻辑） | 验证函数、类、模块的确定性行为 |
| 2 | 集成测试（Harness E2E） | 每次 CI | mock/takeover | 验证多模块协作：Agent 生命周期、IPC、DB 状态链路 |
| 3 | Smoke 测试 | Nightly / 手动 | 真实模型 API | 验证完整对话链路能跑通，模型返回合理回复 |
| 4 | 前端 E2E（Playwright） | 每次 CI | 无 | 验证 Web UI 渲染、路由跳转、WebSocket 连接、交互行为 |

---

## 第 1 层：单元测试

**范围：** 纯逻辑模块，无外部依赖或依赖已被 vitest.mock() 替换。

**规则：**
- 使用 `:memory:` SQLite（不读磁盘）
- 不启动 CoreService，不创建 socket
- 不调用真实模型 API
- 一个测试文件对应一个源文件
- 只测本模块公开 contract，不 import 其他模块内部实现
- 断言确定性输出，不断言 AI 生成内容

**命名：** `<module>.test.ts`，与源文件同目录。

**示例场景：**
- Schema 校验（manifest 解析、config 解析）
- 数据库迁移（表创建、字段约束）
- 纯计算函数（ID 生成、路径拼接、格式化）
- 注册表增删查（AgentRegistry.register/unregister）
- 事件总线分发（EventBus.emit/on 回调触发）

---

## 第 2 层：集成测试（Harness E2E）

**范围：** 真实启动 CoreService + 多个 Agent 进程，通过 socket 通信，但模型调用被 mock/takeover 截断。

**规则：**
- 必须使用 `TestHarness`（hermetic `BERRY_HOME`、清理 credential、固定 TZ/LANG）
- LLM 模式为 `mock` 或 `takeover`，绝不调用真实模型
- 可安装真实 Agent（entry.ts 使用 `startModuleAgent`）并执行完整任务
- 断言 DB 状态链路：`agent_tasks.status`、`agent_lifecycle_events`、`conversations`
- 断言文件系统副作用（Agent 真实读写文件）
- 超时设置宽松（15-30s），因为包含进程启动
- 后台任务用 `harness.waitIdle()` 等待

**命名：** `<module>-e2e.test.ts`

**示例场景：**
- Agent 生命周期全流程（install → enable → disable → upgrade → remove）
- Agent 执行真实任务（file-editor 修改文件、echo 回显）
- Socket handler 路由（所有 `agents.*` 命令）
- 权限拒绝/通过链路
- 多步骤串行任务的状态一致性

---

## 第 3 层：Smoke 测试

**范围：** 真实启动 CoreService，使用真实模型 API 进行端到端对话。

**规则：**
- 文件位于 `src/testing/smoke.test.ts`
- 依赖环境变量 `BERRY_TEST_LIVE_API_KEY`（或 `LLM_API_KEY`）
- 无 key 时自动 skip（`describe.skipIf`）
- 使用 `resolveRealTestConfig` + `applyRealTestEnv` 设置 hermetic 环境 + 真实凭据
- 不断言具体内容（模型输出不确定），只断言：
  - 响应非空
  - 响应类型正确（string）
  - 无 error 返回
  - session 能保持上下文
- 超时宽松（60-90s），因模型推理耗时
- CI 中作为 nightly job 运行，不阻塞普通 PR

**运行方式：**
```bash
# 手动运行
BERRY_TEST_LIVE_API_KEY=<key> LLM_BASE_URL=<url> LLM_MODEL=<model> npm test -- src/testing/smoke.test.ts

# 或使用项目默认配置
LLM_API_KEY=tp-xxx npm test -- src/testing/smoke.test.ts
```

## 第 4 层：前端 E2E 测试（Playwright）

**范围：** 启动后端 + 构建后的前端，在真实浏览器中验证 Web UI 行为。

**工具：** Playwright（跨浏览器 Chromium/Firefox/WebKit，自动等待，内置断言，追踪回放）

**规则：**
- 测试文件位于 `web/e2e/` 目录
- 测试前需先构建前端（`npm run build:web`）并启动后端服务
- 不依赖真实模型 API — 后端以 mock/takeover 模式启动
- 验证内容：
  - 页面路由跳转正确（首页、聊天、Agent 管理、任务、设置）
  - WebSocket 连接建立和消息渲染
  - 组件交互（输入框输入、按钮点击、侧边栏切换）
  - 暗色/亮色主题切换
  - 响应式布局（移动端/桌面端）
  - **移动端专项**：
    - 底部导航栏在移动端可见、高亮当前页（`md:hidden`）
    - 所有操作按钮触控目标 ≥ 44px（消息操作、侧边栏按钮、表单提交）
    - hover 依赖的操作按钮在移动端始终可见
    - iOS 安全区域不被内容遮挡（顶部导航栏、底部输入框）
    - 移动端侧边栏以 overlay 形式打开/关闭
  - 不验证 AI 生成的具体回复内容

**命名：** `<feature>.spec.ts`，位于 `web/e2e/` 目录。

**运行方式：**
```bash
# 安装 Playwright 浏览器（首次）
npx playwright install

# 运行所有前端 E2E 测试
npx playwright test --config web/playwright.config.ts

# 运行单个测试
npx playwright test --config web/playwright.config.ts web/e2e/chat.spec.ts

# 带 UI 模式调试
npx playwright test --config web/playwright.config.ts --ui
```

## 禁止的测试模式

以下模式提供虚假信心，不允许出现：

1. **Mock 中间层测试** — 对 mock 了所有依赖的高层模块做断言（如 mock AgentManager + mock DB 测试 CoreService 逻辑）。这类测试只验证 mock 的行为，不验证真实系统。
2. **断言 AI 输出内容** — 不要在单元/集成测试中 expect 模型生成特定文本。模型输出不确定，这类断言会随模型更新而脆弱地失败。
3. **跨模块 import 内部实现** — 测试只能依赖目标模块的公开 contract，不 import 私有函数。
4. **无 hermetic 环境的 E2E** — 集成/Smoke 测试必须用临时目录，不能读写 `~/.berry`。

## 环境与基建

### Hermetic Environment

所有非单元测试必须在隔离环境运行：
- 临时 `BERRY_HOME`（`mkdtempSync`）
- 清除 `ANTHROPIC_*`、`CLAUDE_*`、`OPENAI_*` 环境变量
- 固定 `TZ=UTC`、`LANG=en_US.UTF-8`
- 测试结束后清理临时目录

### TestHarness（`src/testing/harness.ts`）

集成测试统一入口：
- `new TestHarness({ llmMode: 'mock' })` — 创建 harness
- `harness.start()` — 启动 CoreService + 等待 Agent ready
- `harness.sendMessage(msg)` — 通过 socket 发送消息
- `harness.waitIdle()` — 等待所有 agent_tasks 完成
- `harness.getDb()` — 访问测试 DB 验证状态
- `harness.stop()` — 优雅停止服务 + 清理

### Real Test Profile（`src/cli/real-test-profile.ts`）

Smoke 测试凭据解析：
- 优先 `BERRY_TEST_LIVE_*` 环境变量
- 回退 `LLM_*` 环境变量
- 再回退项目 config 默认值
- `applyRealTestEnv()` 设置 `BERRY_LLM_MODE=live` + hermetic home

## 运行命令

```bash
npm test                                    # 全部（smoke 无 key 会 skip）
npm test -- --watch                         # watch 模式
npm test -- src/kernel/agent-lifecycle.test.ts  # 单文件
npm run typecheck                           # 类型检查（提交前必过）
```
