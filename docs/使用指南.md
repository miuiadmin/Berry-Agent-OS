# 使用指南

> Berry 的用户面文档：安装、CLI、TUI 命令面、数据目录、环境变量、技能、记忆与委派。

## 1. 安装与启动

要求 Node.js ≥ 22.19。从源码运行：

```bash
git clone <repo> && cd berry
npm install
npm run build
npm link        # 装上 berry 命令

berry           # TUI 交互
```

三个 CLI 入口（手写 argv，无命令框架）：

| 命令 | 行为 |
|------|------|
| `berry` | TUI 交互。缺省**续接当前目录最新会话**；无会话则新建 |
| `berry run "<指令>"` | 单次执行（headless），退出码即结果。适合脚本/CI |
| `berry dump-config` | 打印生效组合诊断：模型、组合树合成结果、每行插件装载状态。**只读不落库**，排查配置问题的第一入口 |

退出码编舞：正常退出 0；SIGINT 首次优雅退出 0、二次 130；SIGTERM 143；SIGHUP 129。

## 2. 模型与凭证

- 缺省模型 `anthropic/claude-sonnet-5`，`APP_MODEL` 环境变量覆盖（格式 `provider/model-id`）。
- provider 凭证走 pi-ai 凭证链：凭证表（SQLite `credentials`，随 pi-ai 授权流写入）或 provider 环境变量（如 `ANTHROPIC_API_KEY`）。
- `berry dump-config` 可查看当前模型与 provider 状态。

## 3. TUI 命令面

输入以 `/` 开头即命令。内置命令：

| 命令 | 行为 |
|------|------|
| `/help` | 列出全部已注册命令（含插件贡献的） |
| `/quit` | 退出（等价 Ctrl+C 优雅退出） |
| `/new` | 开新会话（旧会话保留在库中） |
| `/usage` | 用量面板：今日/近 7 日 tokens、会话 top、模型分布、goal 预算联查（llm/usage 底账只读投影） |
| `/skills` | 技能清单与激活状态 |
| `/plugins` | 组合树与插件装载状态（每行 activated / failed / skipped 及原因） |
| `/plugin-install <来源>` | 安装文件插件进组合树 |
| `/plugin-toggle <id>` | 启用/禁用某插件行（官方件也可禁——真·可卸） |
| `/plugin-update <id>` | 更新某插件行 |
| `/reload` | 热重载插件集（卸载→重读组合树→重装） |
| `/skill:<名>` | 显式激活某技能（随技能快照逐个注册，`/help` 可见） |

插件贡献的命令（随官方全家桶在场）：

| 命令 | 来源 | 行为 |
|------|------|------|
| `/goal` | goal 插件 | 长目标管理：查看状态；`resume` 重新激活（重启后降级 needs-resume 时）；`stop` 人工停止 |
| `/tick` | scheduler 插件 | 定时任务：`add <name> <prompt>` 添加 / `list` 列出 / `rm` 删除 / `run` 手动触发一次（先过防打架闸，再抢占执行——第一刀仅手动，定时触发随第二刀） |

命令注册表同名后写胜出（与组合树语义一致）；插件命令 handler 出错以通知呈现，不崩界面。

## 4. 数据目录

缺省 `~/.berry/`（`APP_DATA_DIR` 覆盖）：

```
~/.berry/
├── sessions.db          # SQLite 单库（WAL）：会话事件日志 + 记忆库 + goals + 凭证/模型目录
├── overlay.yaml         # 组合树覆写（不存在 = 用官方默认层，首启零配置即合法）
├── project-aliases.json # 项目根别名表（不存在 = 零重定向；项目目录改名/移位后配
│                        #   { "现根绝对路径": "记账根绝对路径" } 续用旧记忆）
├── skills/              # 技能目录（每个子目录一份 SKILL.md）
└── plugins/             # 文件插件装机子树
```

数据目录与库文件随首次启动自动创建（显式 `APP_DB_PATH` 时建其父目录），无需手动建目录。

会话按启动目录（cwd）归属：每个项目目录有自己的会话序列，TUI 启动续接该目录最新一条。

## 5. 环境变量

| 变量 | 作用 | 缺省 |
|------|------|------|
| `APP_MODEL` | 覆盖缺省模型（`provider/model-id`） | `anthropic/claude-sonnet-5` |
| `APP_DATA_DIR` | 数据目录 | `~/.berry` |
| `APP_DB_PATH` | SQLite 库文件路径 | `<数据目录>/sessions.db` |
| `APP_LOG_LEVEL` | 日志级别 debug / info / warn / error | debug（代码上仅 `NODE_ENV=production` 转 info，三入口均不设——实际恒 debug；覆盖用本变量） |

## 6. 技能（SKILL.md）

技能 = 一个目录 + 一份 `SKILL.md`（YAML 前置元数据 + Markdown 指令体）。放好即生效，无需注册。发现目录（按优先序）：

1. `<项目>/.agents/skills/` — 项目内技能（设计上仅受信工作区注入项目层；当前版本受信判定缺省放行，判定机制随后续纵切接入）
2. `~/.berry/skills/` — 用户全局（Berry 原生）
3. `~/.agents/skills/` 与 `~/.claude/skills/` — agentskills.io 生态两目录原生兼容扫描

- **渐进披露**：系统提示词只注入技能清单（名字 + 描述），指令体由模型按需用 `read` 工具加载——不占常驻上下文。
- 前置元数据可设 `disable-model-invocation: true`（kebab-case 键名，只人可用，模型不可主动加载；TS 字段名 `disableModelInvocation`）。
- `/skills` 查看清单与激活状态。

## 7. 内建工具族（模型可见动词）

| 工具 | 语义 |
|------|------|
| `read` / `write` / `edit` / `ls` | fs 工具族。读走 CAS 观察态（读后写检测外部改动），写受可写根 fence |
| `find` / `grep` | 检索族。`find` 按 glob 模式找文件，`grep` 按正则搜内容（`files_with_matches` / 带行号 `content` 双模式，可加 `glob` 过滤）。gitignore 语义、二进制自动跳过、单文件 256KiB 扫描护栏、结果达 200 条早停 |
| `agent` | 委派子代理执行一次性任务（subagent 插件在场时）。前台阻塞返回汇报；`background: true` 立返任务 id、结算自动通知 |
| `goal_get` / `goal_set` / `goal_update` | 长目标管理（goal 插件在场时）。completed 必附 evidence、blocked 必附 note——参数校验段执法，不靠提示词自觉 |
| `bash` | 命令执行（exec 件聚落）。一次性执行无交互 stdin；超时缺省 120s 上限 600s；输出 60KiB 保尾截断；受限档下写类命令被拒时结果带 `[sandbox: …]` 标记，可携 `sandbox_permissions` + `justification` 成对发起升权审批 |
| `memory_write` / `memory_forget` / `memory_restore` / `memory_read` / `memory_search` | 记忆库五件（memory 插件在场时）。`memory_search` 联合记忆库与历史会话全文检索 |

所有工具调用过三段管道：参数 schema 校验 → 安全守门（沙箱/审批/可写根）→ 执行。守门决策（gate/decision）落 durable 日志可审计。

## 8. 记忆系统在会话里的样子（memory 插件在场时）

- **常驻简报**：系统提示词里有 `memory/core` 段——高置信记忆的稳定摘要（重建时点冻结，prompt cache 友好）。
- **按需检索**：每轮按你的 query 注入至多几条相关记忆（hidden 消息，不进时间线）。
- **简报差分**：简报面在会话中变化时（新记忆入库/条目离开），下一轮请求尾注入「+ 新增 / ~ 修正 / − 撤回」差分说明，同时落 `memory/diff` durable 事件——重放会话即重现当时的记忆视图。
- **引用回写**：注入行带 `[m:短id]` 标记，模型作答引用即计入该条目效用（排序/保活的依据）。
- **遗忘**：让模型「忘掉这条」走 `memory_forget`（软删，可 restore）；用户终审权最大——插件的一切自动裁决都可被显式动作覆盖。

## 9. 长目标续跑（goal 插件在场时）

`goal_set` 设定目标（含预算帽）后，插件在每次 run 结算时检查：目标 completed 且预算未尽 → 自动注入续跑提示。守护：

- **激活权在人类**：重启后 active 目标降级 needs-resume，`/goal resume` 重新授权才续跑。
- **预算刹车**：本会话 token 用量达帽即停（stopped/budget），不失控烧钱。
- 完成必须附 evidence——空口无凭不算完成。
