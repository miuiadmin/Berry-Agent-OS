# 使用指南

> Berry 的用户面文档：安装、CLI、TUI 命令面、数据目录、环境变量、技能、记忆与委派。

## 1. 安装、升级与卸载

要求 Node.js ≥ 22.19。三种安装方式：

**方式一：一键脚本**（分步状态显示，失败带原因与出路口）：

```bash
curl -fsSL <仓库>/scripts/install.sh | sh   # <仓库> = 本项目仓库地址（npm 发布定档时回填直链）
```

脚本做三件事：检查 Node ≥ 22.19（只查不装，缺失指引发官方指引）→ `npm i -g berryagent` → `berry --version` 验证；完成显示欢迎横幅与下一步指引。

**方式二：npm 直装**（npm 发布后可用）：

```bash
npm i -g berryagent
```

**方式三：源码**（开发者）：

```bash
git clone <repo> && cd berry
npm install
npm run build
npm link        # 装上 berry 命令

berry           # TUI 交互
```

### 升级

```bash
berry upgrade   # 升级维护动词：查 registry 更新 → 有新版即 npm i -g berryagent@<版本>
```

三态行为：**npm 装机形态**自动完成升级并提示重启（运行中进程持旧版，重启 TUI / `berry daemon stop && start` 生效）；**源码形态**不自动执行（源码树可能有本地改动）——打印四步指引（`git pull` → `npm install` → `npm run build` → `npm link`）；**未发布态**（registry 无包）诚实告知。TUI 内 `/upgrade` 为只读薄壳：查更新、展示结果、指引退出后执行 `berry upgrade`。缺省零版本检查不变——不跑 upgrade 即零网络（升级是用户显式维护动作，与 agent 运行时网络面正交）。

### 卸载

```bash
npm rm -g berryagent        # npm 形态；源码形态 = 删 clone 目录 + npm rm link（或 rm $(npm prefix -g)/bin/berry）
rm -rf ~/.berry             # 数据目录（记忆/会话/装机物/凭证/别名表——删除前可 /memory-export 导出记忆）
```

首启欢迎与 `/guide`：第一次启动（库文件不存在）TUI 自动出现欢迎块（版本、默认应用、三条快速上手）；`/guide` 随时可看同一份快速上手参考（命令、文档地图、升级卸载一句）。

首启即用：无配置直接进 **coder 代码智能体应用**（出厂默认应用——`default: true` 清单键声明；无参启动、`/new`、`berry run` 不带 `--app` 均进此域，coding 优先的软件工程协作体验）。想换纯对话体验：`/app chat` 进入对话应用域。默认应用被禁用（组件缺场）时回落 chat；两者都不可用则起最小壳 + 警示，`berry dump-config` 可查默认应用解析诊断。

| 命令                                   | 行为                                                                                                                                                            |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `berry`                                | TUI 交互。缺省**续接当前目录最新会话**；无会话则新建                                                                                                            |
| `berry run --app-file <path> "<指令>"` | 快速试件（开发指南 §8）：入口文件路径直接跑一次——零装机零挂载零落盘（组合树注入临时行，退出后恢复原状）。开发应用的主入口                                       |
| `berry run "<指令>"`                   | 单次执行（headless），退出码即结果。适合脚本/CI                                                                                                                 |
| `berry attach`                         | 接上常驻 daemon 的纯客户端（零本地装配零本地库）：SSE 续流 + 审批应答，缺省选本工作区最近活跃会话。无 daemon 运行时给指引退出非零。daemon 形态全貌见运维手册 §9 |
| `berry upgrade`                        | 升级维护动词：查 registry 更新 → npm 形态自升级 / 源码形态给指引 / 未发布态诚实告知（用户显式维护动作，缺省零版本检查不变）                                     |
| `berry dump-config`                    | 打印生效组合诊断：模型、组合树合成结果、每行应用装载状态。**:memory: 全装配零落盘**（真实装载流程全跑、会话主库在内存即弃——所见即实装），排查配置问题的第一入口 |

旗标：`--version` 输出版本号与文化代号（如 `1.0.0-alpha.0 "Peiligang"`——每个 major 版本以中国考古文化命名，裴李岗〔距今约 9000 年·教科书认定中国最早新石器文化〕= 1.x 时代）；`--help` 两个入口通用；`--debug` 日志提级；`berry run --app <应用id>` 进入指定应用开新域单发（缺省不传 = 默认应用〔出厂 canAfford 读的账；手动跑任务式单发而不想吃前台预算时用，`--tick` runner 固定此档）；`berry run --tick <任务名>` 到点执行入口（OS 定时调起的进程走这里：读任务行 → due 复闸 → 抢占 → 单发，可加 `--read-only --background` 与 runner 同款任务面旗标）；`berry run --sandbox-host` 宿主沙箱单发（宿主进程套 OS 沙箱 wrapper——macOS seatbelt / Linux bwrap；检出后 CLI 重 exec 自身，本进程连同全部装载件跑在沙箱内。可写面 = 档位根 ∪ 数据目录〔库与凭证必须可写〕。诚实边界：数据目录内部互害关不住〔策略并集粒度〕/ 非网络沙箱——出网默认放行〔LLM API 刚需〕/ seatbelt profile 非稳定公开接口随 macOS 漂移 / Windows 无后端 fail-closed 拒跑〔退出码 1〕）；`--port <n>` Web 通道开面（`berry` / `berry run` 两入口收；`dump-config` 不收——诊断命令不起监听，只报 webui 行态）：本次启动给 `webui` 行注入 `enabled: true, port: n`，本机浏览器访问 `http://127.0.0.1:<n>` 即得会话呈现面——SPA 界面（会话清单 / 对话流〔markdown 渲染 + 工具卡 + 流式打字〕/ todo 面板 / 跨入口审批〔TUI 弹窗与网页审批卡同题竞速，先答者胜且败侧自动收场——TUI 弹窗落撤销说明行；后台会话的审批在侧栏挂角标，非当前会话也可应答；带「始终允许」草案的卡多一档常驻授权〕/ 回退转录行〔/rewind 落账的系统行〕/ `@` 补全〔@ 键弹出工作区文件路径，`@路径#` 二段弹出该文件符号表〕；消息主列表恒走拉投影腿，SSE 事件流只驱动当前轮次的活体尾部；已闭会话只读可回看，页内可直接开新会话）+ HTTP 微路由十三端点（auth 一次性引导/health/sessions 清单/sessions 开新/messages/todo/submit/interrupt 打断/events + approvals 未决清单与 decide 应答/workspace 文件与符号两补全）。监听钉死回环三防线（127.0.0.1 绑定 fail-at-startup / Host 白名单 / Origin 硬防线——单机形态不开局域面）+ token 鉴权恒在场（「监听 ⇒ 鉴权」：本次启动自动生成进程内一次性 token、不落盘——TUI 横幅 / run stderr 披露，浏览器首屏贴 token 经 `/api/auth` 换 cookie，或请求头 `Authorization: Bearer` 携带；daemon 形态用 `daemon.json` 持久 token 同门同律）。旗标只影响本次 boot、不写 overlay；与 overlay `enabled: true` 并存时旗标端口胜。端口被占 = 启动即拒（`WEBUI_PORT_IN_USE`——诚实失败，换端口或停占用者）；缺省不开（`enabled` 缺省 false，零监听零资源）。`--no-apps` 安全模式（`berry` / `berry run` / `berry dump-config` 三入口通用）——boot 时组合树空装，默认层与 overlay 全跳过、只装不可卸内核件 + Ring 1 硬装配，用于**坏应用锁死启动的自救**：以此旗标起最小内核壳（TUI 无对话驱动但命令面/应用管理完好），修好 `overlay.yaml` 后 `/reload` 即恢复全树（旗标只影响本次 boot，/reload 读盘不受它约束）。`berry dump-config --no-apps` 同径可见（打印标记行 + 只剩 Ring 1 行的树）。

退出码编舞：正常退出 0；SIGTERM 143；SIGHUP 129。SIGINT 分档——单会话（TUI 只一个活动会话 / headless run）首次即优雅退出 0、二次 130；多会话在跑时首次 Ctrl+C 只**打断聚焦会话的当前 run**（终值记 aborted，排队消息落审计不跑，退出与后台会话不受扰），打断结算后再按才是新的首次语义，run 未结算窗口内连按两次才 130 硬退。

## 2. 模型与凭证

- 缺省模型 `anthropic/claude-sonnet-5`，`APP_MODEL` 环境变量覆盖（格式 `provider/model-id`）。
- provider 凭证走 pi-ai 凭证链：凭证表（SQLite `credentials`，随 pi-ai 授权流写入）或 provider 环境变量（如 `ANTHROPIC_API_KEY`）。
- `berry dump-config` 可查看当前模型与 provider 状态。

## 3. TUI 命令面

输入以 `/` 开头即命令。输入补全：`/` 触发命令名补全（Tab 选定）；`@` 触发 mention 补全——`@` 文件段（第一段）列出工作区文件路径（依赖 [fd](https://github.com/sharkdp/fd) 可执行在 PATH（Debian/Ubuntu 装 `fd-find` 后实名 `fdfind`，两者都认），或 `APP_FD_PATH` 指定；缺失时文件段无建议、命令段与符号段不受影响——诚实缺席不报错）；`@路径#` 两段式时弹出该文件的符号表（`符号名:行号`，语言服务器件在场且该文件类型有路由时；件缺席或熔断时退回文件段行为），选中后代换为 `@路径#符号名` 完整 token。审批弹窗的撤销行为：同一审批在 TUI 与网页双开时同题竞速先答者胜，先决侧落账后另一侧自动收场——TUI 弹窗侧收场时以撤销说明行（如「该审批已在网页端应答」）替代答案行收屏，输入框即刻释放可继续对话。审批在身时打断或退出同样自动收场（Ctrl+C 打断聚焦 run / Ctrl+D·/quit 退出时，在身与排队的审批弹窗以撤销说明行〔如「该运行已被打断」〕收屏，落账记 cancel——打断不是拒绝，不会再弹「不要重试」类引导；退出路的收场兜底保证等待中的会话能正常结算落盘）。内置命令：

| 命令                                       | 行为                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/help`                                    | 列出全部已注册命令（含应用贡献的）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `/quit`                                    | 退出（多会话在跑也退出——恒全序列；Ctrl+C 才是「打断聚焦会话」键，两者分流）                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `/new`                                     | 开新会话（旧会话退役停摆，事件账保留）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `/app`                                     | 多会话前台：裸调列活动会话（●聚焦 / ⧗后台工作中 / ·空闲，含停摆计数；清单尾部披露可用应用〔缺场应用已滤，默认应用带 `(默认)` 标——如 `chat、coder(默认)、hermes`〕）；`/app new` 开新并聚焦（旧会话驻留后台不退役——新会话恒开默认应用域）；`/app <序号\|id前缀>` 切换前台（序号按当次清单会漂移，id 前缀更稳；切换零准入拒——run 中切入切出均合法，非聚焦会话只落摘要行不绞屏）；`/app <应用清单id> [消息]` 进入该应用开新域（清单 id 命中优先于会话序号/前缀寻址——进入是创建新域不是切换；带消息 = 进入后作为首条用户消息直接提交） |
| `/usage`                                   | 用量面板：今日/近 7 日 tokens、会话 top、模型分布、goal 预算联查（llm/usage 底账只读投影）                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `/allowlist`                               | 免问清单管理：裸调枚举 allowlist 条目（路径前缀 / bash 词干两族，过期态如实标注）；`/allowlist rm <序号>` 撤销。守门命中 allowlist 即免审批执行，但 `reason=allowlist:<序>` 落 gate/decision 审计账——免问≠免账                                                                                                                                                                                                                                                                                                                     |

| `/apps`                                    | 组合树与装载状态（每行 activated / failed / skipped 及原因；**已装未挂**的仓库态件以 ◇ 行呈现并带挂载指引——「装了没挂」不可静默）                                                                                                                                                                                                                                                                                                                                                                                                  |
| `/apps-install <来源>`                     | 装机（npm 包名 / git URL / 本地路径）——**仓库态**：代码入装机子树 + 出处落账，零生效不落组合行（装完见 /apps ◇ 行）                                                                                                                                                                                                                                                                                                                                                                                                                |
| `/apps-mount <装机id> --apps <应用id>[,…]` | 挂载生效：写组合行（`--apps` 必填多值——第三方件挂应用作用域，逗号分隔或重复旗标，多值 = 多应用共享件；`--carrier main\|worker\|external` 显式降格位〔缺省不落 sandbox 块 = external 进程墙——闩一出生即隔离〕、`--row-id <行id>` 行 id 显式命名位、`--config '<json>'` 行初始配置**唯 `--carrier main` 行可携**——分域行的 config 校验面在域侧，宿主拒绝代校验）并链 `/reload` 热应用                                                                                                                                                |
| `/apps-unmount <行id>`                     | 卸挂载：删组合行保代码与数据域（重挂走 /apps-mount；受影响会话警示随回执呈报）并链 `/reload` 热应用                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `/apps-toggle <行id>`                      | 启用/禁用某装载行（官方件也可禁——真·可卸；临时停用保配置走此命令，移出组合树走 unmount）                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `/apps-update <装机id>`                    | 更新装机件（npm 重装 / git 重克隆 / local 提示改动即见；键域 = 装机推导 id——已装未挂的仓库态件也可更新）                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `/apps-uninstall <id>`                     | 卸载件——**两段式**：裸调只检视（装机物 / 数据域体积 / 自定义事件词 / 受影响会话计数 + 确认指引），再打 `/apps-uninstall <id> --confirm` 才执行（`--purge-data` 连数据域清除，默认保留）。Ring 1 底座行拒卸；重跑行不在 = 残迹收尾或无动作速报（幂等）                                                                                                                                                                                                                                                                              |
| `/reload [--app <应用id>]`                 | 热重载：裸调全量（锚作用域 LIFO 回卷 → 重读组合树 → 重装）；`--app` **单区重载**——只换该应用名下第三方挂载行，他应用运行时不动（驱动与会话不死、systemPrompt 不重建；不在册应用 id 报错并在附在册清单）。回执带**卸词集警示**（该区旧自定义事件词消失点名——重装即回、改名即旧词永失）。run 进行中不拒——排队按应用分槽，本次 run 结束后自动执行                                                                                                                                                                                     |
| `/skill:<名>`                              | 显式激活某技能（随技能快照逐个注册，`/help` 可见）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `/guide`                                   | 快速上手参考（版本/核心命令/文档地图/升级与卸载一句——「上手引导」的常驻形态；首启欢迎块同一份骨架）                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `/upgrade`                                 | 检查更新并展示结果（只读薄壳：本地/远端版本 + 形态）；升级执行走 `berry upgrade` 命令——升级自身运行包 + 重启是用户动作，TUI 内不自动执行                                                                                                                                                                                                                                                                                                                                                                                           |

| `/obs-alerts`                       | obs 件        | 观测告警规则面：`list` 清单（id/度量/阈值/窗/冷却/触发时刻）；`add <sum\|avg\|max> <表.列> <op> <阈值> [窗h=24] [冷却min=60]` 添加（度量闭集 = llm/tool/turn/approval 四表的度量列，如 `llm.tokens_in`）；`rm <id>` 删除；`enable\|disable <id>` 启停——**只通知不执法**（执法在宿主预算/频率护栏，告警是预警前置；触发 = obs/alert 事件 + 通知；无 UI 通道在场的无头进程不触发也不消耗冷却——冷却只被有观众的进程消耗，观众到场后下次评估照常触发） |

命令注册表同名后写胜出（与组合树语义一致）；应用命令 handler 出错以通知呈现，不崩界面。

> 两态已生效（应用中心装载批 D2）：装机与挂载分离——**应用独立不生效**，装机只是入仓，`/apps-mount --apps` 写行才进组合树（上表即现行行为）。装应用 = 提示式批量装机 + 组件挂入该应用一步到位（`/app-install` 随首个第三方应用包需求落码）。

## 6. 技能（SKILL.md）与项目指令（AGENTS.md）

技能 = 一个目录 + 一份 `SKILL.md`（YAML 前置元数据 + Markdown 指令体）。放好即生效，无需注册。发现目录（按优先序）：

1. `<项目>/.agents/skills/` — 项目内技能（设计上仅受信工作区注入项目层；当前版本受信判定缺省放行，判定机制随后续纵切接入）
2. `~/.berry/skills/` — 用户全局（Berry 原生）
3. `~/.agents/skills/` 与 `~/.claude/skills/` — agentskills.io 生态两目录原生兼容扫描
4. 宿主包内 `skills/` — 出厂技能（commit-checklist / apps-quickstart / troubleshooting 样例随包分发，优先级最低——同名时你的技能恒压过出厂件）

- **渐进披露**：系统提示词只注入技能清单（名字 + 描述），指令体由模型按需用 `read` 工具加载——不占常驻上下文。
- 前置元数据可设 `disable-model-invocation: true`（kebab-case 键名，只人可用，模型不可主动加载；TS 字段名 `disableModelInvocation`）。
- `/skills` 查看清单与激活状态。

**项目指令文件**（行为约束，常驻系统提示词——与技能的按需加载相反）：纯 Markdown，无需前置元数据。发现四层全量拼接（通用在前、项目殿后）：

1. `~/.berry/AGENTS.md` — 用户全局（Berry 原生）
2. `~/.agents/AGENTS.md` — agents.md 跨工具标准
3. `~/.claude/CLAUDE.md` — Claude Code 生态兼容（现成文件直接复用）
4. 工作区根 `AGENTS.md`（优先）或 `CLAUDE.md` — 项目层（同层至多取一份，防 symlink 双读）

- 单文件 64KiB 上限，超限截断入段（带截断标注）。
- 改指令文件后 `/reload` 生效（重建时点重读，会话中途不热更——保护 prompt cache）。

## 8. 记忆系统在会话里的样子（memory 件在场时）

- **常驻简报**：系统提示词里有 `memory/core` 段——高置信记忆的稳定摘要（重建时点冻结，prompt cache 友好）。
- **按需检索**：每轮按你的 query 注入至多几条相关记忆（hidden 消息，不进时间线）。
- **简报差分**：简报面在会话中变化时（新记忆入库/条目离开），下一轮请求尾注入「+ 新增 / ~ 修正 / − 撤回」差分说明，同时落 `memory/diff` durable 事件——重放会话即重现当时的记忆视图。
- **引用回写**：注入行带 `[m:短id]` 标记，模型作答引用即计入该条目效用（排序/保活的依据）。
- **遗忘**：让模型「忘掉这条」走 `memory_forget`（软删，可 restore）；用户终审权最大——件的一切自动裁决都可被显式动作覆盖。
- **记忆晋升为技能**：反复命中的教训/约定（failure/insight/convention 类、攒了二次证据或被引用过）会以「可晋升候选」出现在常驻简报尾行——模型可提议把它整理成 SKILL.md 写入技能目录（frontmatter 带 `provenance` 溯源到源记忆；经用户审批 + `/reload` 生效），随后源记忆退场（知识搬进技能，搬家不是复制；冻结条目除外）。晋升是显式动作，永不自动发生。
- **持有面**：临时性记忆可带 TTL（到期自动离开注入面，行保留、可恢复）；「这条永远记住」走冻结（恒驻简报、免过期免覆写）；条目内容变更有版本链可回滚；每次注入/检索/引用落访问流水可审计。`/memory-export` / `/memory-import` 命令把整库导出/导入 JSONL（明文文件，注意去向）。

## 9. 长目标续跑（goal 件在场时）

`goal_set` 设定目标（含预算帽）后，件在每次 run 结算时检查：目标 completed 且预算未尽 → 自动注入续跑提示。守护：

- **激活权在人类**：重启后 active 目标降级 needs-resume，`/goal resume` 重新授权才续跑（`/goal resume <goalId>` 可跨会话领养一个降级目标——行重绑到当前会话）；`/tick` 定时任务到点拉起的续接不算人类重启（不降级——挂钟轮自持授权）。
- **预算刹车**：本会话 token 用量（含经委派子代理折进本会话的花销）达帽即停（stopped/budget），不失控烧钱。
- **唤醒帽**：自动续跑（自激）连续至多 3 轮、24h 窗内至多 12 次唤醒——超帽暂停投递（目标保持 active，等下一次 run 结算或用户消息再试）；用户手写消息恢复连续轮预算。这是自激失控的硬保险，与预算刹车互补（一个防转得太多、一个防烧得太多）。
- **停滞硬停**：模型每轮申报 `outcome`（轮结算形）——连续 3 轮只报表面动作（surface_only）或两幕「改了没生效」（outcome_gap）即停（stopped/stalls），不陪着空转。
- **续跑轮只读缺省**：无人值守的续跑轮工具面收窄为只读（检索/阅读 + goal 结算件）；目标确需写文件/执行命令，`goal_set` 时申报 `needsWrite: true` 开洞（`/goal` 状态行可见）。
- 完成必须附 evidence——空口无凭不算完成；每轮结算的 `evidence` 落 durable 事件链累积成证据账本，`goal_get` 可回看。
- **计划态跨轮**：goal 激活后 todo 清单不再按「用户消息」切段——从激活点起整段折叠回显，跨轮持续在场，长目标的步骤表不因对话往返清零（goal 结束或无 goal 时回落到按用户消息切段的常规行为）。
- **完成判据机器化**：todo 项可申报 `gate` 判据门（文件在场 / 命令退出码 / 诊断级三源）——置 completed 时同步验证，不过即整笔拒绝（`GOAL_GATE_FAILED`，回执带 `kind` / `reason` 结构化前缀）；`goal_update` 的 completed 另受未完项否决——todo 前沿还有未完或缓办项就不许结算完成。
- **轮间沉淀**：会话投影超过模型窗口半阈时，件在 run 结算点自动生成「目标推进摘要」（objective 锚定——围绕目标重组信息而非对话复述），已沉淀段落折叠省上下文；摘要花销自报计入 goal 预算（越限同笔刹停）。事实源 = durable `goal/summary` 事件，goals 表摘要列只是缓存（丢列可回填）。
- **挂钟后台唤醒**：`/goal wake <schedule>` 给目标挂 OS 定时钟（schedule 同 `/tick` 三形状）——到点经 tick 会话投递拉起续跑轮，提示词动态渲染时态文本（目标 + 最新摘要 + 预算余额）。挂钟轮 v1 只读（后台路不附写面）、计账走 background 道、不受连续自激帽约束（外部钟非自激链）但受窗口帽与预算双闸；目标终态或降级时同笔停钟（行留史），`/goal resume` 重挂并治愈陈旧会话指针。`wake off` 摘钟。

## 10. 声明式子代理（agents/*.md）

一个 Markdown 文件就是一个具名子代理——frontmatter 声明元数据，正文即系统提示（与 Claude Code 的 `.claude/agents/*.md` 同形，可直接复用现成文件）：

```markdown
  - read
  - grep
model: anthropic/claude-sonnet-5 # 可选：子模型覆盖
---

你是资深审读员，逐行审查。
```

- **发现位置**（同名时前面的压过后面）：项目 `.agents/agents/` → `~/.berry/agents/` → `~/.agents/agents/` → `~/.claude/agents/`。
- **静态工具**：每个文件自动生成 `agent_<name>` 委派工具——模型看到的是具体工具而非动态选择器；通用 `agent` 工具不受影响。
- **文件即约束**：正文固定子代理人格（请求无法覆盖）、`tools` 与请求工具名单取交集（只收窄不改宽）、`model` 覆盖子模型。
- 坏文件（缺 description / 正文空 / YAML 坏）warning 跳过不影响启动；文件名须为合法工具字符（字母/数字/`_`/`-`）。

## 11. 工作区快照回退（checkpoint 件在场时）

checkpoint 件在每次 run 的**首个变更类工具执行前**自动拍工作区快照（pre-mutation 捕获）：文件未变走 stat 快径零拷贝，变了才落 sha256 blob；同会话内容未变不重复拍。快照资产存件数据域 `~/.berry/apps/checkpoint/`（`blobs/` 内容仓 + `manifests/` 清单），不进 SQLite。

`/rewind` 两段事务：先恢复文件到快照点，再把会话 fork 到快照对应的事件边界并切前台——**文件与会话一起退回**，不会出现「文件回到了旧样子、对话还在聊新进度」的错位。

配置键（`overlay.yaml` 组合树 checkpoint 行 `config` 下）：

| 键              | 含义                      | 缺省                         |
| --------------- | ------------------------- | ---------------------------- |
| `maxSnapshots`  | 每会话快照保留上限        | 50                           |
| `maxTotalBytes` | blob 仓总字节软帽         | 512MiB                       |
| `exclude`       | 排除目录列表（glob 前缀） | `['node_modules/', '.git/']` |

诚实边界：

- **回退永不删文件**（无删除铁律）：快照只记录它见过的文件——回退后快照点之后**新建**的文件留在原地不动，回执带遗留清单如实呈报。
- **guard 防误退**：每次回退前自动拍一条 guard 快照（◆ 标记），退错了再 `/rewind` 那条 guard 即回到回退前。
- **worker / external 载体行进程外捕获不可达**（v1 诚实边界）：分域行跑在独立进程，宿主侧快照监听对它们的工具调用不可见——主线程行（含全部官方件）全覆盖。
- `checkpoint/rewind` durable 事件是 UI 转录行的数据源，v1 时间线不渲染该行（数据在库，渲染随后续 UI 批跟进）。

## 12. 语言智能（lsp 件在场时）

lsp 件是语言服务器（LSP 协议）桥：把外部语言服务器（TypeScript / Python / Go / Rust …各自官方 server）的**诊断、符号、定义、引用**接成模型可用工具，并在你写完代码后**立即把诊断附在写工具的结果里**——「写完即知类型错」不需要再跑一遍 `bash tsc`。

两档能力：

- **写后诊断注入（自动）**：`write` / `edit` 执行后，件把该文件同步给路由命中的服务器并等一窗诊断（3500ms 硬帽），有结果就追加在工具输出尾部。首次触达某服务器时是冷启预热——该次注记「预热中，本次未附诊断」，下一次写入起生效。
- **四工具（模型主动）**：`lsp_diagnostics`（某文件全部诊断）、`lsp_symbols`（符号大纲）、`lsp_definitions`（某位置符号的定义处，`path` + `line` + `column`，坐标 1-based）、`lsp_references`（全部引用处）。

配置（`overlay.yaml` 组合树 lsp 行 `config.servers`——**未配置即整件惰性**，零进程零工具开销；`command` 必须是绝对路径，v1 不认 `npx` 相对解析）：

```yaml
rows:
  - id: lsp
    config:
      servers:
        ts:
          command: /opt/homebrew/bin/typescript-language-server
          args: ['--stdio']
          languages: ['.ts', '.tsx'] # 扩展名路由表——多服务器命中取声明序首
        py:
          command: /usr/local/bin/pylsp
          languages: ['.py']
```

单服务器可调键：`startup_timeout_sec`（握手 30）、`request_timeout_sec`（单请求 15）、`diagnostics_timeout_ms`（工具面诊断等待 8000）。服务器名限字母/数字/连字符；扩展名未命中任何路由表时工具如实报路由表、不猜服务器。

诚实边界：

- **同步协议 v1 = 全文推送**（didChange Full）：每次写后发整文件，大文件多服务器时带宽放大——增量同步（syncKind 2）挂账后续。
- **诊断超时不是失败**：服务器索引中未及回流时如实注记「稍后重试」，不算工具错误。
- **服务器 3 连败熔断**：spawn/握手连续失败即记 dead 并通知（此后调用直接回「已熔断」），修好配置 `/reload` 重置。
- 服务器子进程跑在宿主沙箱档内（confine 同 MCP server），临时文件钉数据域 `~/.berry/lsp/tmp/`——不写系统 /tmp。
