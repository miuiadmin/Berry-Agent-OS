# 输出规范

## 命名规则

| 概念 | 正确用法 | 不要用 |
|------|---------|--------|
| 模型调用层 | LLM API | gateway, provider |
| 通信渠道 | Message Channel | adapter |
| 供应商实现 | backend / adapter（仅代码内部） | provider |

## 控制台输出语言

- 面向用户的控制台输出（CLI、REPL、日志、错误提示）默认使用**中文**
- 产品名、模块名、命令、参数、文件名、类型名保留英文
- 不要输出整句英文提示

```
✓ 已启动 Berry Service
✓ 权限请求已拒绝
✓ 正在检查 Agent 状态

✗ Berry Service started
✗ Permission denied
```

- `--json` 模式：字段名英文，用户可见文案优先中文

## 日志系统

**等级：** `error` > `warn` > `info` > `debug`

**输出路由：**
- 人类输出 → stdout
- 错误和进度日志 → stderr
- `--json` 模式 → stdout 只输出合法 JSON

**禁止直接 `console.log/error`**，必须通过 `ConsoleRenderer` 或 `getLogger(module)`。

**运行时调级：**
```bash
berry logs level debug              # 临时
berry logs level info --persist     # 持久
berry logs level debug --ttl 10m    # 定时恢复
```

## Run Artifact

每次 `berry run` / `berry test run` 生成独立 artifact 目录：

```
~/.berry/runs/{run_id}/
├── berry.log.jsonl    # 结构化日志
├── console.jsonl      # 控制台帧（stream + text + seq + timestamp）
├── stdout.log         # 原始 stdout
├── stderr.log         # 原始 stderr
└── result.json        # 运行元数据（status, duration, command）
```

`berry run --json` 返回 `runId` + `artifactDir`。

## 脱敏规则

以下内容自动 redact，不可明文输出：
- 匹配 `api_key|token|authorization|cookie|password|secret|credential` 的字段
- URL 参数中的 `token|key|secret|access_token|api_key|auth`
- 以 `sk-`、`ghp_`、`tp-`、`AKIA`、`xoxb-` 等开头的字符串
- Bearer token → `Bearer [REDACTED]`

## 前端移动端适配规范

所有 Web 前端代码（`web/src/`）必须遵循以下移动端适配规则。此规范与 `CLAUDE.md` 中的「Web 前端移动端适配（硬规则）」配套执行。

### 响应式断点

| 断点 | Tailwind 前缀 | 含义 |
|------|-------------|------|
| < 640px | （默认） | 小屏手机 |
| ≥ 640px | `sm:` | 大屏手机 |
| ≥ 768px | `md:` | 平板 / 桌面端分界（**主断点**） |
| ≥ 1024px | `lg:` | 大屏桌面 |

**约定**：移动端/桌面端切换以 `md:` (768px) 为主断点。类名顺序为移动端在前、桌面端在后。

### 触控目标

| 场景 | 规则 | 示例 |
|------|------|------|
| 图标按钮 | 移动端 `size-11`（44px），桌面端 `md:size-9` | `className="size-11 md:size-9"` |
| 文字按钮 | 移动端 `py-2.5`（~40px 高），桌面端 `md:py-2` | `className="py-2.5 md:py-2"` |
| 表单输入 | 移动端 `h-10`（40px），桌面端 `md:h-8` | `className="h-10 md:h-8"` |
| Native select | 移动端 `min-h-[44px]` | `className="min-h-[44px] md:min-h-0"` |
| 内联操作按钮 | 移动端 `p-2`，桌面端 `md:p-1` | `className="p-2 md:p-1"` |

**最小触控区域 44px × 44px**（Apple HIG）。不得修改 `Button` 组件基础尺寸，在调用处覆盖。

### hover → touch 适配

移动端无 `:hover`，所有依赖 hover 显示的操作按钮必须使用以下模式：

```tsx
// 移动端始终可见，桌面端 hover 显示
className="opacity-100 md:opacity-0 md:group-hover:opacity-100"
```

**适用场景**：
- 消息操作按钮（复制、编辑、删除）
- 列表项操作按钮（重命名、删除、导出）
- 任何通过 `group-hover:opacity-100` 控制可见性的交互元素

### 事件处理

| 输入类型 | 推荐事件 | 禁止 |
|---------|---------|------|
| 鼠标 + 触控 | `onPointerMove` / `onPointerLeave` | `onMouseMove` / `onMouseLeave`（仅鼠标） |
| Tooltip 浮层 | `onPointerEnter` + `onClick` toggle | `onMouseEnter` / `onMouseLeave`（仅鼠标） |
| 按钮/链接 | `onClick` + `active:` 视觉反馈 | 仅 `:hover` 反馈 |

### 安全区域（iOS）

```html
<!-- index.html -->
<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover" />
```

| 位置 | CSS | 用途 |
|------|-----|------|
| 底部导航栏 | `pb-[env(safe-area-inset-bottom,0px)]` | iPhone 底部横条 |
| 聊天输入框 | `pb-[calc(0.75rem+env(safe-area-inset-bottom,0px))]` | 输入框底部安全区 |
| 移动端顶栏 | `pt-[env(safe-area-inset-top,0px)] md:pt-0` | 刘海屏顶部 |
| Lightbox 关闭按钮 | `top-[calc(1rem+env(safe-area-inset-top,0px))]` | 全屏遮罩顶部 |

### 字体大小

| 场景 | 移动端 | 桌面端 |
|------|--------|--------|
| 正文 / 代码块 | `text-[13px]` | `md:text-xs`（12px） |
| 辅助信息 | `text-[11px]` | 保持 |
| 图表标签 | `fontSize={10}` | 保持 |
| 标签/徽章 | `text-[11px]` | 保持 |

**禁止** `text-[10px]` 用于非代码/非纯数据内容。代码块和 pre 标签内的内容允许 `text-[10px]`。

### 布局模式

| 桌面端 | 移动端 | 实现方式 |
|--------|--------|---------|
| 固定侧边栏 | 底部导航栏 `MobileBottomNav`（`md:hidden`） | `fixed bottom-0 inset-x-0 z-30` |
| 侧边栏抽屉 | Overlay + 左滑动画 | `fixed inset-y-0 left-0 z-50 transform md:relative md:translate-x-0` |
| 表格视图 | 卡片列表 | `hidden md:block` + `md:hidden` |
| 横向 tab 栏 | 水平滚动 + 渐变遮罩 | `overflow-x-auto scrollbar-none` |

### Z-Index 层级

| 层级 | z-index | 用途 |
|------|---------|------|
| 底部导航栏 | `z-30` | `MobileBottomNav` |
| 侧边栏 overlay | `z-40` | 背景遮罩 |
| 侧边栏本体 | `z-50` | 导航菜单 / 会话列表 |
| Dialog / Lightbox | `z-50` | 模态弹窗 |
| 拖拽上传遮罩 | `z-50` | `DragOverlay` |

不得使用 `z-[100]` 等任意值，保持 z-index 在标准范围内。
