# 插件规则

> ⚠️ **2026-08-22：1.0 重置起草中**。本文描述 old-v2（当前运行代码）的现状与规范，开发照常适用；1.0 落地时是否沿用待重审（[设计文档索引](../设计文档/index.md)）。

## 核心原则

- 插件是独立扩展包（`plugin.json` + `entry.ts`），不是散落的 `.ts` 文件
- Manifest 是第一契约，所有 CLI 命令支持 `--json`
- 插件不得：直接调用 LLM API、绕过 permission token、读取 `process.env`、import `src/kernel/*`
- 插件工具必须声明 `inputSchema`、`outputSchema`、`permissionScope`
- 高风险权限需 Brain 审核 + 用户确认
- 插件系统已有 v2 runtime（`src/plugins/runtime-v2.ts`、`src/plugins/isolated-runtime.ts`、`src/contracts/plugins-v2.ts`），支持隔离沙箱执行

## 插件 Manifest（plugin.json）

```jsonc
{
  "apiVersion": "berry.plugin.v1",
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "描述",
  "source": "user",                  // bundled|generated|user|installed
  "riskLevel": "low",               // low|medium|high
  "capabilities": {},
  "permissions": {},
  "tools": [{
    "name": "tool-name",
    "title": "工具标题",
    "description": "工具描述",
    "permissionScope": "readonly",   // readonly|file|shell|network
    "inputSchema": { ... },
    "outputSchema": { ... },
    "examples": [],
    "failureModes": []
  }]
}
```

## entry.ts 插件定义

```typescript
// entry.ts：纯 default export 对象，零 import——loader 直接动态加载；
// `definePlugin` 只是宿主侧 src/plugins/sdk.ts 的类型 helper（不存在可安装的 SDK 包）
export default {
  name: 'my-plugin',
  tools: {
    'tool-name': async (input, ctx) => {
      ctx.log.info('执行中...');
      return { result: '...' };
    },
  },
  init: async () => { /* 加载时调用 */ },
  dispose: async () => { /* 卸载时调用 */ },
};
```

`PluginContext` 提供：`pluginName`、`toolName`、`log`（`PluginLogger` 对象：debug/info/warn/error）、`storage`、`config`、`fetch`、`emit`。

## 生命周期状态

```
draft → validating → pending_review → enabled
                                    ↘ pending_user_confirm → enabled
                   ↘ failed
enabled ⟷ disabled
enabled → quarantined
enabled → rolled_back
```

## 验证检查

`berry plugins validate <name>` 执行：
1. 必需文件：`plugin.json`、`entry.ts`
2. Manifest schema 合规
3. Entry.ts 静态分析（文本扫描）：
   - 未使用 `definePlugin` → **告警**（非失败）
   - 禁止 `process.env` 访问 → 失败
   - 禁止 import `src/kernel` → 失败（`src/memory` 不在扫描范围）
   - 禁止直接 import LLM SDK（`@anthropic-ai/sdk` / openai / ai-sdk）→ 失败

## 权限范围映射

| permissionScope | dangerLevel | 说明 |
|-----------------|-------------|------|
| readonly | safe | 只读操作 |
| file | moderate | 文件读写 |
| shell | dangerous | 命令执行 |
| network | dangerous | 网络请求 |

## 添加插件

1. 用 `berry plugins scaffold <name> --description <描述>` 生成草稿（落在插件目录 `~/.berry/plugins/<name>/`，`SERVICE_HOME` 可覆盖根——PluginRegistry 只扫描该目录，**无** `src/plugins/bundled` 内置机制）
2. 编写 `plugin.json`、`entry.ts` 和至少一个 `tests/*.fixture.json`
3. 运行 `berry plugins validate <name> --json`
4. `berry plugins enable <name>` 启用（走验证 + Brain 审核）

## CLI 命令

```bash
berry plugins list [--json]
berry plugins inspect <name> [--json]
berry plugins validate <name> [--json]
berry plugins test <name> [--json]        # 执行 fixture 测试
berry plugins dry-run <name> <tool> [--json]
berry plugins enable|disable|delete <name>
berry plugins scaffold <name>             # 生成模板
```
