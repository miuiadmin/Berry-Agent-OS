## 触发条件

- 用户明确要求检查部署状态
- 用户询问服务是否健康
- 用户请求查看部署日志

## 执行规则

### 1. 检查清单

按顺序执行以下检查：

1. **服务状态** — 检查关键服务是否运行中
2. **端口监听** — 确认端口正常绑定
3. **日志异常** — 扫描最近日志中的 ERROR/FATAL
4. **资源占用** — 检查 CPU/内存/磁盘
5. **依赖服务** — 确认数据库、缓存等上游可达

### 2. 输出格式

```markdown
## 部署状态检查报告

| 检查项 | 状态 | 详情 |
|--------|------|------|
| 服务进程 | ✅/❌ | ... |
| 端口监听 | ✅/❌ | ... |
| 日志异常 | ✅/❌ | ... |
| 资源占用 | ✅/❌ | ... |
| 依赖服务 | ✅/❌ | ... |

### 问题汇总
- ...

### 建议操作
- ...
```

### 3. 注意事项

- 此技能仅供用户主动调用，不会自动触发
- 如果无法访问服务器，明确告知用户并建议手动检查
- 对于生产环境操作要格外谨慎
- 只读检查，不执行任何修改操作
